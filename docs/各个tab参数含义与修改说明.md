# 各个tab参数含义与修改说明

## Tab1: View

`View` 是新的统一绘图页，用于同时观察 FIP 和 eDAS 时域曲线、PSD 和 eDAS Space-Time 图。

### 曲线选择

| 参数 | 含义 | 建议 |
|---|---|---|
| Curve1 | 第一条时域曲线的数据源，可选 `Off`、`DAS Channel`、`FIP/FIP1/FIP2` | 双 FIP 时建议选 `FIP1` |
| Curve2 | 第二条时域曲线的数据源，可选 `Off`、`DAS Channel`、`FIP/FIP1/FIP2` | 双 FIP 时建议选 `FIP2` |
| DAS通道 | `DAS Channel` 曲线显示的通道号 | 与现场待观察位置一致 |
| 显示时长 | 时域曲线保留的时间窗口 | 半天测试可适当缩短以降低绘图压力 |
| FIP绘图传感器 | Tab1/FIP 当前主处理传感器 | 单 FIP 为 `FIP1`，双 FIP 可切换 |

### DAS曲线预处理

| 参数 | 含义 |
|---|---|
| DAS滤波 | 是否对 eDAS 曲线显示使用带通滤波 |
| DAS低频 / DAS高频 | eDAS 曲线显示带通频率范围 |

### FIP预处理

| 参数 | 含义 |
|---|---|
| 滤波类型 | FIP 处理链使用的滤波类型 |
| 低频 / 高频 | FIP 处理链滤波范围 |
| 阶数 | FIP 滤波器阶数 |
| 降采样 | FIP 处理链降采样因子，影响显示、PSD 和存储有效采样率 |

### 刷新与点数

| 参数 | 含义 |
|---|---|
| FIP刷新 | FIP 曲线最小刷新间隔 |
| eDAS刷新 | eDAS 曲线和 Space-Time 最小刷新间隔 |
| 曲线点数 | 每条时域曲线显示点数上限 |
| 时域按钮 | 控制 Curve1/Curve2 时域图显示 |
| PSD按钮 | 控制右侧 PSD 图显示 |
| View更新 | 控制 View tab 的曲线刷新总开关 |

### PSD

| 参数 | 含义 |
|---|---|
| PSD1 | 是否绘制 Curve1 对应 PSD |
| PSD2 | 是否绘制 Curve2 对应 PSD |
| Welch窗长 | Welch 法每段窗口长度，单位秒 |
| 重叠率 | Welch 法相邻窗口重叠比例 |

PSD1 和 PSD2 画在同一张图上，共用 dB 坐标轴和 legend。PSD 横轴使用对数频率坐标。

### 坐标轴

| 参数 | 含义 |
|---|---|
| 手动范围 | 是否启用手动坐标轴范围 |
| X min / X max | Curve1/Curve2 的时域 X 轴范围 |
| Y min / Y max | Curve1/Curve2 的时域 Y 轴范围 |
| PSD Y min / PSD Y max | PSD 图 dB 轴范围 |
| 应用坐标轴 | 立即应用手动范围 |
| 自动范围 | 恢复 pyqtgraph 自动范围 |

### Space-Time

| 参数 | 含义 |
|---|---|
| 通道起点 / 通道终点 | eDAS Space-Time 显示的通道范围 |
| 时间降采样 | Space-Time 时间方向降采样 |
| 空间降采样 | Space-Time 空间方向降采样 |
| 色图 | Space-Time 颜色映射 |
| Vmin / Vmax | Space-Time 色标范围 |

## Tab2: Data

`Data` 是新的通信、同步、存储和配置页，不包含绘图。

### FIP通信参数

| 参数 | 含义 |
|---|---|
| FIP监听地址 | 本软件作为 FIP TCP 服务端时绑定的本机地址；推荐 `0.0.0.0` 监听所有网卡 |
| FIP端口 | FIP TCP 端口 |
| 单包时长 | FIP 每个数据包对应的采集时长，默认 `1 s` |
| 采样率(MHz) | FIP 标称采样率 |
| 传感器数量 | FIP 当前传感器路数 |
| 状态 / 包数 / 丢包率 | FIP 通信状态与统计 |

### eDAS通信参数

| 参数 | 含义 |
|---|---|
| eDAS监听地址 | 本软件作为 eDAS TCP 服务端时绑定的本机地址；推荐 `0.0.0.0` 监听所有网卡 |
| eDAS端口 | eDAS TCP 端口 |
| 状态 / 包数 / 缺包数 | eDAS 通信状态与统计 |
| eDAS头信息 | 通道数、采样率、数据字节数、包时长和最近通信号 |

### 通信控制

| 控件 | 含义 |
|---|---|
| 同时启动FIP+eDAS | 同时请求启动两个模块通信，并重置同步统计 |
| 启动FIP通信 | 单独启动或停止 FIP 通信 |
| 启动eDAS通信 | 单独启动或停止 eDAS 通信 |
| FIP/eDAS通信灯 | 灰色为未启动，红色为启动未成功，绿色为成功连接或收到数据 |

### 通信统计与同步

| 参数 | 含义 |
|---|---|
| FIP成功/失败/丢包率 | FIP 通信成功包数、失败计数和丢包率 |
| eDAS成功/失败/丢包率 | eDAS 通信成功包数、失败计数和丢包率 |
| 首次包时间差 | 首个匹配同序号包的接收时间差 |
| 最新同序号包时间差 | 最新匹配同序号包的接收时间差 |
| 平均时间差 | 所有匹配包的平均接收时间差 |
| 已匹配包数 | 已经可计算时间差的同序号包数量 |

### 存储

| 控件或参数 | 含义 |
|---|---|
| 同时存储FIP+eDAS | 启用联合存储 |
| FIP存储 | 单独启用 FIP 原始/处理数据存储 |
| eDAS存储 | 单独启用 eDAS 原始数据存储 |
| FIP/eDAS存储灯 | 灰色为未启动，红色为启动但未成功写入，绿色为已有成功写入 |
| 联合路径 | FIP+eDAS 联合存储目录 |
| 联合间隔 | 联合存储时间片长度 |
| 缓存秒数 | 联合存储缓存窗口 |
| eDAS路径 | eDAS 独立存储目录 |
| 每文件块数 | eDAS 独立存储每个文件包含的数据块数 |
| 队列包数 | eDAS 独立存储队列容量 |
| 最近联合存储 / 最近eDAS存储 | 最近一次存储状态或文件名 |

## Tab3: 检测页

新的第三个 tab 保留旧 Tab2 的检测功能。

| 区域 | 含义 |
|---|---|
| 检测总开关 | 控制 FIP 短时特征提取和告警检测是否运行 |
| 特征选择 | 控制每个特征是否计算、是否绘图 |
| 滤波与窗口 | 控制检测前预处理和短时窗口参数 |
| 阈值 | 控制不同特征的触发灵敏度 |
| 触发存储 | 控制告警前后数据截取与保存 |
| 告警表 | 显示检测到的事件 |

该 tab 默认不启动，避免无需求时占用 CPU。

## Tab4: Setting

| 参数 | 含义 |
|---|---|
| GUI字体 | 全局 Qt 控件字体大小 |
| 图题字体 | pyqtgraph 图件标题字体大小 |
| 坐标轴标签 | 坐标轴名称字体大小 |
| 刻度字体 | 坐标刻度字体大小 |
| 应用全局设置 | 立即应用以上设置 |

## 修改建议

1. 现场联调时，先在 `Data` tab 同时启动 FIP+eDAS，再回到 `View` tab 观察曲线和 PSD。
2. 若通信灯为红色，先检查监听地址、端口和对应设备是否正在发送数据。
3. 若通信成功但同步时间差偏大，优先检查两套设备是否确实同时开始采集，而不是只同时启动了上位机监听。
4. 若 View 刷新卡顿，优先降低 `曲线点数`、增大刷新间隔或缩短显示时长。
5. 若 PSD 噪声大，增大 Welch 窗长或调整重叠率；若实时性更重要，减小窗长。

## 2026-07-19 GUI补充调整

1. 服务端监听地址说明：
   - 软件作为 TCP 服务端时，监听地址必须是当前电脑本机网卡地址。
   - 不确定具体网卡地址时，推荐填写 `0.0.0.0`，表示监听所有本机网卡。
   - 设备或客户端连接本软件时，应填写本机实际网卡 IP，例如 `192.168.x.x`；客户端不能把 `0.0.0.0` 当作目标地址。
   - 本机回环测试时可使用 `127.0.0.1`。
2. View tab 左侧参数区改为更多两列参数布局：FIP 预处理、刷新参数、PSD、坐标轴参数均减少纵向占用。
3. View tab 三个绘图开关按钮统一为 `时域 ON/OFF`、`PSD ON/OFF`、`刷新 ON/OFF`，并统一按钮高度、圆角和颜色语义。
4. Space-Time 色标恢复到图右侧，避免放在图下方挤压时域高度。
5. Data、Storage、Setting 和检测页主要按钮统一尺寸与样式：蓝色表示可启动/可执行，红色表示正在运行可停止，灰色表示开关关闭或次级操作。

## 2026-07-19 参数自动保存与恢复

1. GUI 会把最近一次参数快照自动保存到本地文件：

```text
config/gui_last_state.json
```

2. 参数变化后会延迟约 `700 ms` 自动写盘，避免连续输入时频繁保存。
3. 关闭窗口前会强制保存一次，确保最后修改的参数不丢失。
4. 下次打开软件时会自动读取该文件，并恢复通信监听地址、端口、FIP 采样参数、滤波参数、View 绘图参数、PSD 参数、坐标轴、存储路径、eDAS 参数、检测参数和字体设置。
5. FIP 通信启动前会使用当前 GUI 中的监听地址和端口，因此恢复后的 FIP 监听参数会在下一次启动 FIP 通信时生效。
6. 启动时只恢复参数，不会自动启动 FIP/eDAS 通信；检测页总开关也保持关闭，避免打开软件后后台线程自行运行。
7. `保存配置` 按钮会立即写入本地快照；`加载配置` 按钮会重新读取本地快照；`重置配置` 会恢复代码默认值并刷新本地快照。
8. GUI 快照与基础系统配置 `config/app_config.json` 分离，现场 UI 参数不会覆盖基础配置文件。
9. `config/gui_last_state.json` 是本机运行态文件，已加入 `.gitignore`，不会随代码提交。

## 2026-07-19 View/Data二次调整参数说明

### View: Curve级绘图参数

| 参数 | 含义 |
|---|---|
| Curve1 来源 | 控制 Curve1 时域图绘制 `Off`、`DAS Channel`、`FIP1` 或 `FIP2` |
| Curve2 来源 | 控制 Curve2 时域图绘制 `Off`、`DAS Channel`、`FIP1` 或 `FIP2` |
| C1 DAS通道 | 当 Curve1 来源为 `DAS Channel` 时，指定 Curve1 抽取的 eDAS 通道号 |
| C2 DAS通道 | 当 Curve2 来源为 `DAS Channel` 时，指定 Curve2 抽取的 eDAS 通道号；默认 `10` |
| C1 DAS带通 | 对 Curve1 的 DAS 曲线启用带通预处理 |
| C2 DAS带通 | 对 Curve2 的 DAS 曲线启用带通预处理 |
| C1低频 / C1高频 | Curve1 DAS 带通滤波频带 |
| C2低频 / C2高频 | Curve2 DAS 带通滤波频带 |
| 显示时长 | DAS 曲线和 Space-Time 的滚动显示时间窗口 |
| FIP处理目标 | FIP 处理链当前选用的传感器；Curve 时域绘图自身可直接选择 `FIP1` 或 `FIP2` |

默认值：

1. Curve1 默认绘制 `FIP1`。
2. Curve2 默认绘制 `DAS Channel`。
3. Curve2 默认 eDAS 通道为 `10`。
4. 若需要同时查看两个 eDAS 通道，将 Curve1 和 Curve2 都设为 `DAS Channel`，再分别设置 `C1 DAS通道` 和 `C2 DAS通道`。
5. 若不需要查看 FIP 曲线，可将 Curve1/Curve2 均设为 `DAS Channel` 或 `Off`。

### View: PSD图

| 图件 | 含义 |
|---|---|
| PSD1 | Curve1 当前时域数据的 Welch PSD，位于 Curve1 右侧 |
| PSD2 | Curve2 当前时域数据的 Welch PSD，位于 Curve2 右侧 |
| PSD1 开关 | 仅控制 PSD1 计算和绘制 |
| PSD2 开关 | 仅控制 PSD2 计算和绘制 |
| Welch窗长 | Welch 计算每段窗口长度，单位秒 |
| 重叠率 | Welch 相邻窗口重叠比例 |

说明：

1. PSD1 和 PSD2 是两个独立图件，不共享坐标轴。
2. 两个 PSD 都以 dB 为纵轴单位。
3. `PSD ON/OFF` 是总开关；单独关闭 PSD1 或 PSD2 时，只清空对应 PSD 图。
4. 手动坐标轴中的 PSD Y 范围会同时应用到两个 PSD 图，但两个图件仍互不共享 pyqtgraph 坐标轴对象。
