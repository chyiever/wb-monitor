# GUI 美化与布局优化记录

> 日期：2026-09-17
> 目标：面向科研/数据采集监测软件，统一视觉语言、梳理控件层级、提升可操作性。

## 1. 总体设计原则

参考科研数据处理软件（如 Origin、MATLAB、NI SignalExpress、Polytec Data Management）
的通用设计语言，本次美化遵循：

1. **浅色专业主题**：以大面积的浅灰蓝背景 + 白色卡片承载信息，主色 `#2563eb`（蓝）
   用于选中、焦点、主操作，避免高饱和撞色。
2. **信息分层**：用 `QGroupBox` 卡片把“开关 / 参数 / 状态”分开，同类控件对齐成网格，
   一眼看清每个模块的功能边界。
3. **弱化干扰**：去掉控件焦点虚线框、统一圆角与边框、hover/pressed 三态反馈。
4. **一致性**：所有按钮、输入框、下拉框、SpinBox 使用同一套边框/圆角/选中色，
   状态灯、计数标签保持既有语义（绿=正常、红=异常、灰=未启动）。

## 2. 全局样式（`src/ui/main_window.py`）

在 `_apply_global_focus_style()` 中统一挂载应用级 QSS：

| 元素 | 样式 |
|---|---|
| 全局字体 | `Microsoft YaHei` / `微软雅黑` |
| 窗口背景 | `#f2f5f9`，文字 `#1f2937` |
| `QGroupBox` | 白底、`#d8dee9` 边框、8px 圆角、蓝色标题 |
| `QPushButton` | 白底浅边框；hover 淡蓝底；checked 蓝色实心白字 |
| `QLineEdit/QSpinBox/QDoubleSpinBox/QComboBox` | 白底、`#c9d4e3` 边框、4px 圆角；focus 蓝色边框 + 淡蓝底 |
| `QTabBar` | 未选中浅灰，选中白底蓝字加粗，蓝色下划线 |
| `QHeaderView/QTableView` | 表头浅灰、网格线 `#e2e8f0`、选中淡蓝 |
| `QScrollBar` | 圆角滑轨，hover 变深 |
| `QToolTip` | 深色底白字 |
| `QSplitter` | 浅灰分隔线，hover 变蓝 |

Tab 栏、顶部标题栏同步改为白色 + 蓝色下边框，与全局主题一致。

## 3. Tab2 存储区重构（“存储控制与日志”拆为三个子框）

原“存储控制与日志”把所有参数堆在一个大框内，操作拥挤。现拆分为：

1. **存储开关与路径**：三个存储开关按钮 + 三条路径输入（联合/FIP/eDAS）。
2. **存储参数**：FIP间隔、联合间隔、缓存、eDAS块/文件、eDAS队列、FIP降采样、
   联合格式（bin/npz/h5）、H5压缩。
3. **存储状态与日志**：预计文件大小、FIP/eDAS 成功失败计数、联合Last、eDAS Last。

每个子框各自成卡片，状态标签保持在底部，避免运行时被参数挤动。

## 4. 可操作性提升

- 存储开关按钮采用主操作按钮样式（绿/红语义），启用状态一目了然。
- 联合格式与 H5压缩提供工具提示（ToolTip）说明各自适用场景。
- 默认绘图窗口 2 s、联合文件 2 s、刷新 1 s，与“断丝监测”实时观察节奏一致。

## 2026-10-21 标题栏、图件字体与 Setting 紧凑布局

### 需求与实现

1. 标题栏：移除蓝色下边框，使用 `QWidget#appHeader` 限定样式范围，并为其 QLabel 清除边框和文字装饰，消除软件名称及左上角 Logo 下方的横线。
2. 图件字体：所有时域、PSD、时空及信号检测图的四侧坐标轴刻度统一为 Times New Roman（新罗马）；轴标签通过 labelStyle 指定字体族与像素字号，色标刻度/标签同步处理。Setting 中原有字号调节继续生效。
3. Tab3 可见性：默认仅显示 View / Data / Setting。Setting 新增“显示 Tab3（信号检测）”，勾选后在 Data 与 Setting 之间插入页面，取消后隐藏；隐藏当前页时切回 View。页面对象保留，显示开关不改变检测运行状态。
4. 配置持久化：增加 `setting.show_tab3`，支持自动保存、手动保存及恢复；旧配置没有该字段时按隐藏处理。
5. Setting 布局：五个数值输入框宽度统一为 120 px、数值右对齐；设置卡片限制最大宽度为 620 px，左上对齐，保存按钮左对齐。
6. Git 上传：`.gitignore` 增加 `fipedasREAD/dist/`，本地打包文件保留，程序源码分支不纳入该目录。
