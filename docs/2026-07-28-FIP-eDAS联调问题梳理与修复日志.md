# 2026-07-28 FIP-eDAS联调问题梳理与修复日志

## 一、问题背景

本次问题来自现场测试日志：

- `logs/pccp_monitor_2026-07-28_12-15-53.log`
- 测试过程：第一次启动时 eDAS 未开通信，仅 FIP 数据进入；停止后重新测试，FIP 与 eDAS 同时进入。
- 用户观察：
  1. FIP 波形显示很粗，怀疑相位展开或绘图链路有问题。
  2. 软件运行几秒后卡顿，鼠标出现小圆圈。
  3. View/Tab1 波形一放大界面卡死。
  4. GUI 每行参数显示不全，相邻行上下字符遮挡。
  5. 全局显示设置修改后需要重启才能生效，希望立即生效。
  6. FIP 数据默认不乘以 `π`；“乘以 `π`”和“相位展开”必须通过 GUI 勾选框成套控制。

## 二、日志证据与问题优先级

### P0：FIP 默认相位处理链路错误

日志中 FIP 原始解析值为工程量级：

- `FIP_TCP_PARSE comm=0 ... decoded_range=[-1029.19785,-833.25919]`
- `FIP phase input ... outside normalized [-1, 1]`
- 随后仍进入 `PhaseUnwrapper`，并输出 `unwrapped=... range=[-1029.19319,-1028.06823]`

这说明当前链路默认把 FIP 当作需要相位展开的数据处理。对现场已经是工程相位或弧度量级的数据，这会改变原始形态，造成波形显示不符合预期。

### P1：实时绘图负载过高导致卡顿

eDAS 同时进入后，日志出现多次慢帧：

- `TAB3_NODE das_tcp.slow_receive ... receive_ms=4856.97`
- `TAB3_NODE plot_worker.slow ... elapsed_ms=2694.19 curve_points=5000 matrix_shape=(51, 5000)`
- `TAB3_NODE plot_worker.enqueue drop_oldest`

这说明接收、重组、曲线、空间时间图和 UI 刷新同时工作时，绘图侧已经出现秒级耗时峰值。即使 TCP 接收线程独立，Qt 信号和 UI 绘图仍会争用主线程。

### P2：缩放时自动范围与高密度曲线重绘冲突

View 曲线使用 pyqtgraph `setData` 实时刷新。缩放时若仍启用自动范围，实时 `setData` 会持续触发布局、范围、PSD 缓存刷新，导致用户缩放操作和后台刷新互相抢占，表现为界面卡死。

### P3：GUI 行高不足与全局设置非即时生效

当前 GUI 默认字号较大，但 SpinBox、ComboBox、按钮、复选框、标签的最小高度和布局间距没有按字号同步调整，导致参数行上下字符遮挡。全局显示设置虽然能保存，但运行时应用不完整，用户需要重启才能看到稳定效果。

## 三、FIP 与 eDAS 数据流

### FIP 数据流

1. `src/fip_tab1/fip_tcp_server.py`
   - 监听 FIP TCP 端口。
   - 接收一包 FIP 原始 payload。
   - 解析通信序号、原始整数相位值和解码后的 `phase_data`。

2. `src/main.py::_process_data_packet`
   - 收到 TCP server 的 FIP 包。
   - 读取 GUI 中的 FIP 数量、选中 FIP、单包时长、采样率、相位展开开关。
   - 根据实际点数和 GUI 参数推断真实采样率，避免时间轴错误。
   - 构造 `RawDataPacket` 并送入 Tab1 线程管理器。

3. `src/fip_tab1/fip_tab1_manager.py::DataProcessingThread`
   - 按 FIP 数量拆分 FIP1/FIP2。
   - 修复明显非有限值或极端异常值。
   - 默认路径：原始 FIP 数值原样进入后续链路，不乘 `π`，不相位展开。
   - 勾选 `FIP相位展开` 后：执行 `phase * π`，再执行 `np.unwrap`，即“乘 `π` + 相位展开”成套启用。
   - 对选中的 FIP 应用滤波和降采样，生成显示曲线。
   - 生成 `psd_data`，供 View 的 PSD 或联动显示使用。

4. `src/das_tab3/das_tab3_manager.py::process_fip_processed_data`
   - 接收 Tab1 已处理 FIP 包。
   - 推入 FIP/eDAS 对齐协调器。
   - 将 FIP 曲线数据发送到 View 页面。
   - 供 FIP+eDAS 联合存储读取最近缓存。

5. `src/fip_tab1/fip_tab1_manager.py::DataStorageThread`
   - FIP 存储开启时，独立线程从原始包队列构建存储窗口。
   - 默认存储 `phase_raw_downsampled`。
   - 勾选相位展开后存储 `phase_unwrapped_downsampled`，并写入 `phase_unwrap_enabled` 元数据。

### eDAS 数据流

1. `src/das_tab3/das_tcp_server.py`
   - 监听 eDAS TCP 端口。
   - 读取固定 header：`comm_count / sample_rate_hz / channel_count / data_bytes / packet_duration_seconds`。
   - 按 `data_bytes` 读取 payload，并转换为 `float64` 一维数据。

2. `src/das_tab3/das_tab3_manager.py::_handle_raw_packet`
   - 校验 payload 点数与通道数。
   - reshape 为二维矩阵：`channel_count x samples_per_channel`。
   - 生成 `DASParsedPacket`。
   - 推入 FIP/eDAS 对齐协调器。
   - eDAS 存储开启时送入 eDAS 原始存储线程。
   - 始终送入 eDAS 绘图 worker 队列。

3. `src/das_tab3/das_plot_worker.py`
   - 从最近 eDAS 包历史中抽取曲线通道。
   - 按曲线点数预算降采样。
   - 构建空间时间图滚动矩阵。
   - 按像素预算自动提高时间降采样，避免矩阵过大。
   - 发送 plot-ready payload 给主线程 UI。

4. `src/ui/main_window.py::update_tab3_plot_payload`
   - 更新 eDAS 曲线。
   - 更新空间时间图 `ImageItem`。
   - 当 View 页面不在前台或刷新开关关闭时跳过重绘。

5. 联合对齐与存储
   - `alignment.AlignedSessionCoordinator` 以 FIP/eDAS 的 `comm_count` 和接收时间维护对齐状态。
   - `DASTab3Manager._maybe_store_snapshot` 在 FIP/eDAS 均在线且满足对齐条件时写入联合 npz。

## 四、已完成修复

### 1. FIP 相位展开开关

涉及文件：

- `src/ui/main_window.py`
- `src/main.py`
- `src/fip_tab1/fip_tab1_manager.py`
- `src/processing/phase_unwrap.py`

修复内容：

- 在 View 页 `FIP预处理` 组中新增 `FIP相位展开` 勾选框。
- 默认不勾选。
- 默认链路对 FIP 原始数值不乘 `π`、不相位展开。
- 勾选后强制执行 `phase * π + np.unwrap`。
- 存储路径与处理路径使用同一开关，避免显示和落盘不一致。

- 合成 FIP 数据测试通过：
  - 默认输出逐点等于原始输入。
  - 勾选路径输出等于 `np.unwrap(raw * π)`。

- 新增 UI 文案为 `FIP相位展开`，未发现乱码。

### 2. 绘图负载与缩放卡死修复

涉及文件：

- `src/ui/main_window.py`
- `src/das_tab3/das_plot_worker.py`
- `src/das_tab3/das_tab3_manager.py`

修复内容：

- 关闭 pyqtgraph 全局抗锯齿，降低高密度曲线绘制成本。
- 曲线 downsampling 从 `peak` 改为 `subsample`，避免高密度包络绘制导致线条变粗。
- 默认 FIP/eDAS 刷新间隔调整：
  - FIP：最低 0.2 s，默认 0.5 s。
  - eDAS：最低 0.5 s，默认 0.5 s。
- 默认单曲线点数降为 5000，最大限制 50000。
- eDAS 空间时间图默认像素预算降为 120000，并在 worker 内部强制上限 300000。
- 非 View 页或刷新关闭时，FIP/eDAS 曲线和空间时间图不再重绘。
- 用户手动缩放或平移后，自动范围关闭，避免实时刷新和用户缩放互相抢占。
- View PSD 更新改为延迟合并触发，避免每次曲线 `setData` 立即重算 PSD。

验证：

- `py_compile` 通过。
- eDAS 合成数据预算测试通过：
  - 旧配置传入 `curve_max_points=200000`、`space_time_max_pixels=999999` 时仍被上限保护。
  - 合成空间时间图被限制到 `200 x 1429`，总像素小于 300000。

中文自检：

- 本模块没有新增中文 UI 文案。
- 真实文件中与绘图相关的中文仍为正常文本，例如 `FIP刷新(s)`、`eDAS刷新(s)`、`单曲线点数`。
