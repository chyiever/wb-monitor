# PCCP断丝监测软件 开发需求文档

## 1. 文档概述

### 1.1 文档目的

本文档明确PCCP断丝监测软件的功能需求、技术选型、开发规范等核心内容，作为基于 Python 3.9 + PyQt5 开发该上位机的核心依据，用于指导 Claude Agent 完成项目文件创建、代码编写及本地调试工作。

### 1.2 项目背景

传感器为光纤干涉仪模块(对应Tab1和Tab2)和分布式光纤传感器(对应Ta3和Tab4)。本软件主要从FPGA接收原始数据，通过数据处理，对断丝信号识别和定位。其中干涉仪数据负责信号识别、DAS数据负责定位。软件主要功能为：通信、绘图、识别、定位、存储等功能。 

现在需要先完成第一部分（光纤干涉仪模块：tab1, tab2）的开发：光纤干涉仪数据从FPGA 完成底层解调后，通过 LabVIEW RT 程序向本上位机软件传输解调数据；上位机需完成数据解析（接收数据包、提取数据、拼接）、相位展开、滤波、波形可视化、特征计算（计算短时能量）、阈值检测（输出超过阈值的时间）、数据存储（npz）等核心功能，最终实现对光纤干涉信号的实时处理与异常检测。RT程序和上位机在同一台电脑上。原始数据采样率1MHz，通道数1，数据类型是有符号定点数<?64,32>, 8个字节。

下面是第一部分开发的技术细节。

## 2. 功能需求

### 2.1 数据通信模块

#### 2.1.1 核心功能

- python作为服务器端，与 LabVIEW RT 程序建立 **TCP 稳定连接**，支持手动配置端口号（默认端口可设为 3677）；

- 实时接收 LabVIEW RT 上传的解调数据（一个数据包格式：1个32位整数（含义是通信次数，从1开始，占4个字节）+ 1个32位整数（含义是数据体的字节数，默认是1600000，占4个字节）+数据体（数据类型：有符号定点数<?64,32>, 单个数8个字节，默认0.2s传一次、采样率1MHz，所以数据体长度为200k个数）；

- 数据接收容错处理：断连自动重连、数据校验（防止丢包/错包）、异常数据丢弃（如超出合理范围的无效值）。

#### 2.1.2 技术要求

- 采用多线程设计：通信线程独立于 GUI 主线程，避免界面卡顿；

- 数据缓冲区设计：采用环形缓冲区缓存接收数据，缓冲区大小可配置（默认 10000 条），防止数据溢出。

### 2.2 数据预处理模块

#### 2.2.1 相位展开

- 输入：FPGA 解调后的包裹相位数据（范围 [-1, 1]）；

- 算法：先乘以np.pi，再采用**相位差法**实现相位展开，处理相位跳变（当相邻采样点相位差绝对值 > π 时，自动补偿 2π）（np.unwrap函数）；

- 输出：连续的展开相位数据。

#### 2.2.2 信号滤波

- 支持多种滤波模式（可手动切换）：

    - 高精度滤波：采用**巴特沃斯低通/高通/带通/带阻滤波**（截止频率、阶数可配置，默认 100Hz高通、4 阶，使用scipy等库中已有的函数实现）；

- 滤波后数据需保留原始采样率，无明显相位偏移。

#### 2.2.3 降采样

降采样倍数n可控（1至100的整数）。算法1：是隔n点取一个点；算法2：滑动平均，用一个长度为n窗口的平均值代替窗口，进而实现降采样。

### 2.3 波形可视化模块

#### 2.3.1 核心要求

- 基于 PyQtGraph 的 `PlotWidget + ImageItem` 实现波形刷新：

    - 波形1：显示实时相位/滤波后信号波形（可在参数区切换），支持 X 轴（时间）、Y 轴（相位/幅值）缩放、平移；

    - 波形2：使用未滤波的数据计算PSD（使用welch函数，单位是dB，类型是density，窗口长度为信号长度）横轴、纵轴范围可控（在参数区控制）；

- 刷新频率：适配数据接收速率（默认1s一个包），无界面卡顿；

- 可视化：网格显示。

#### 2.3.2 交互功能

- 波形冻结/恢复：点击按钮可暂停波形刷新，冻结当前画面；

- 数据标注：支持在波形上点击标注时间点、数值，标注信息可保存；

- 视图重置：一键恢复波形默认显示范围。

### 2.4 特征计算模块

#### 2.4.1 短时能量计算

- 算法：对滤波后信号按**滑动时间窗口**（窗口大小可配置，默认 0.05s，重叠50%）计算短时能量：

     $E(n) = \sum_{k=n-N+1}^{n} x(k)^2 $ 

    其中  $N$  为窗口内采样点数， $x(k)$  为窗口内第  $k$  个采样点的信号值；

- 输出：实时更新的短时能量曲线（波形3），可在可视化界面单独显示。

#### 2.4.2 其他可选特征（预留扩展）

- 短时过零率、峰值因子、均方根（RMS），支持用户选择是否计算。

### 2.5 入侵信号检测模块

#### 2.5.1 检测逻辑

- 基于**短时能量阈值法**等算法（用户可自选）实现入侵信号检测：

    1. 计算实时短时能量的基线值（默认取前 10s 数据的均值）；

    2. 当短时能量超过「基线值 × 阈值系数（可配置，默认 3）」且持续时间 > 最小触发时长（默认 0.05s）时，判定为入侵信号；

- 支持手动调整阈值系数、最小触发时长、用于计算特征的滤波参数，支持基线值手动更新/自动更新（如每 10s 刷新一次）。

#### 2.5.2 告警功能

- 入侵信号触发时：本地专门日志文件记录；

- 告警信息包含：触发时间、持续时间、能量值、阈值等，支持手动清除告警。

### 2.6 数据存储模块

#### 2.6.1 存储功能

- 支持两种存储模式：

    - 实时存储：开启后自动将预处理后的数据（展开相位、滤波后信号、短时能量三种可供选择）按指定格式存储，默认30s存一个文件，可调；

    - 触发存储：仅当检测到入侵信号时，存储触发前后指定时长的数据（默认前 5s、后 10s）；

- 存储格式：npz；

- 存储路径：默认存储道D:\PCCP\FIPdata和D:PCCP\FIPmoniter，支持自定义存储目录，文件命名规则为 `FIP_phase_1000000Hz_YYYYMMDD_HHMMSS.格式后缀`。`解调仪数据FIP_phasefilterd_1000000Hz_YYYYMMDD_HHMMSS.格式后缀` `FIP_fea_1000000Hz_YYYYMMDD_HHMMSS.格式后缀`

#### 2.7 系统参数配置模块

- 界面化配置：IP 地址、端口、采样率、滤波参数、检测阈值、存储路径等参数支持界面手动配置，并自动保存为默认配置文件（JSON 格式）；

- 配置文件加载：软件启动时自动加载上次保存的配置，支持配置重置。

## 3. 非功能需求

### 3.1 性能要求

- 数据处理延迟：单通道 1000000Hz 采样率下，从数据接收至波形刷新完成 ≤ 500ms；

- 稳定性：连续运行 24 小时无内存泄漏、无程序崩溃；

- 资源占用：CPU 使用率 ≤ 30%（单通道），内存占用 ≤ 2000MB。

### 3.2 界面要求

- 布局清晰：分为TAB1「参数配置区」（通信、存储、预处理例如滤波参数）+「波形显示区」、TAB2【信号检测区】。详见PCCP-semi-GUI-tab1.png、PCCP-semi-GUI-tab2.png

- 适配性：支持 1920×1080 及以上分辨率显示器，界面元素自适应缩放。

### 3.3 兼容性要求

- 操作系统：Windows 10/11（64 位）；

- 依赖库版本：PyQt5 ≥ 5.15.7，PyQtGraph ≥ 0.13.3，NumPy ≥ 1.23.5，SciPy ≥ 1.9.3。

## 5. 开发与调试规范

### 5.1 开发环境配置

1. 安装 Python 3.9，配置环境变量；

2. 安装依赖库：

    ```Bash
    
    pip install pyqt5==5.15.7 pyqtgraph==0.13.3 numpy==1.23.5 scipy==1.9.3 pandas==1.5.3 h5py==3.7.0
    ```

3. VSCode 配置：安装 Python、PyQt Integration 插件，配置解释器为 Python 3.9。

### 5.2 调试要点

1. 通信模块调试：先通过 TCP 模拟工具（如 NetAssist）发送测试数据，验证数据接收/解析正确性；

2. 相位展开调试：使用预设的包裹相位测试数据（含跳变点），验证展开后相位连续性；

3. 波形刷新调试：监控 GUI 主线程耗时，确保刷新频率达标且无卡顿；

4. 入侵检测调试：使用模拟入侵信号数据，验证阈值触发、告警功能的准确性。

### 5.3 代码规范

- 遵循 PEP 8 编码规范，函数/类添加文档字符串；

- 关键逻辑（如相位展开、入侵检测）添加详细注释；

- 异常处理：对文件读写、网络通信、数据计算等环节添加 try-except 块，记录异常日志。

- 对每个数据流、数据处理的节点，打印日志，便于发现问题定位问题

### 总结

1. **核心功能**：上位机需实现 TCP 数据接收、相位展开/滤波、PlotWidget 波形刷新、短时能量计算、入侵检测、数据存储六大核心模块，且各模块需满足实时性、准确性要求；

2. **技术核心**：基于 Python 3.9 + PyQt5 开发，波形刷新必须采用 PlotWidget + ImageItem 方案，多线程设计避免界面卡顿；

3. **开发规范**：严格软件工程开发规范创建项目，遵循 PEP 8 编码规范，重点调试通信、相位展开、入侵检测等核心逻辑，确保软件稳定运行。
