# View 联合存储、运行状态与完整参数包

日期：2026-10-21；修改仅提交 dev2。

## 入口与职责

- View 第一页：“绘图参数设置…”与“存储参数设置…”两个独立按钮，运行状态区及底部 Start/Stop。
- 联合存储窗口：启用开关、保存目录、文件间隔、FIP 降采样、缓存时长、bin32/bin/npz/h5、H5 压缩。原 FIP 页不再显示这些设置。
- FIP 第三页：FIP 通信、独立 FIP 存储、对齐与存储日志。
- eDAS 第二页：采集及独立 DAS 存储保持原有职责。
- Setting：统一字体和完整传感参数包导入/导出。

存储窗口采用草稿编辑，只有“应用并保存”生效，取消/外部点击不写回。采集或通信运行期间，窗口仍可启停联合存储，但路径、格式、分段等只读；应用入口再次检查运行状态，防止绕过只读控件后修改文件结构。沿用原 manager/worker 信号和停止排空链路。

## 状态与计数规则

Fiber Length 与第二页相同：Points×0.4 m，大于 10000 m 改为 km，分别保留一位/两位小数。

连续运行时长使用单调时钟，从第一路采集/通信启动开始；任一路继续运行即不中断，全部停止后冻结，下一次启动重新计时。它不属于要恢复的参数。

eDAS 灯读取实际采集帧数的推进，FIP 灯读取真实接收包数的推进。灰色表示停止，黄色表示启动后等待数据，绿色表示进度正常，红色表示错误、未连接采集卡或数据超时。超时阈值取至少 5 s，并根据采集显示周期/FIP 包时长扩大。启动按钮状态或 TCP 监听状态本身不代表已成功收数。

存储灯对所有启用的写入链路检查完成进度和错误，尚无完成文件时为黄色；实际完成文件且无已知异常为绿色；写盘失败、丢弃、磁盘不可用/满时为红色，全部关闭为灰色。仅一个链路成功不会掩盖其他启用链路仍在等待。FIP/eDAS 状态灯独立显示数据源健康状况。

“已存储文件数”统计本次打开软件后的成功完成数，分别列出联合、FIP、DAS；不跨软件重启累计，不扫描历史目录。联合文件依据成功保存通知确认存在并防止相邻重复通知；DAS 文件在 flush、fsync、close 成功且含数据帧后计数，未关闭文件与空 BIN/仅头 BZ 不计；FIP 仅在 np.savez 成功后计数，命名序号中的失败尝试不计。FIP 停止排空后的最终统计也同步到界面。

剩余空间按启用链路所在卷显示，未启用时显示配置的联合路径所在卷。每 5 s 查询一次，按磁盘去重；未创建的子目录向上查找已有父目录，磁盘或路径错误显示无法查询，不递归扫描数据文件。

## 自动恢复与 .par

GUI 的 gui_last_state.json 纳入完整 edas_params，与已有 communication、preprocessing、storage、view、setting、tab2、tab3 配置一起保存。eDAS 参数保存会立即更新统一快照，避免 eDAS JSON 已更新而 GUI 快照滞后。旧 GUI 文件没有 edas_params 时沿用单独 edas_last_params.json，之后保存升级为统一快照。启动只恢复参数，不自动启动 FIP/eDAS。

Setting 的“导出参数 .par”可导出当前完整配置，包含 FIP 通信/传感/滤波、eDAS 硬件/采集/相位/裁剪/显示/共享/独立存储、View、联合存储及全局设置。运行状态、采集数组、计时和文件统计不导出。

文件格式为 WBPAR 版本头 + 12 字节随机 nonce + AES-256-GCM 密文/认证标签，明文为压缩 UTF-8 JSON。文件和解压后内容均限 8 MiB，拒绝未知版本、截断、篡改、错误结构及非法数值。使用 JSON，不使用 pickle 或可执行对象反序列化。

密钥为程序内置的便携密钥，无需用户记忆密码，可在相同软件版本的其他电脑导入。此设计用于阻止普通文本直接阅读、提高随意编辑门槛并检测篡改；程序源码可获得时不能承诺保密，不属于密码/账户访问控制系统。数据文件本身的格式和加密状态不变。

导入前要求 FIP/eDAS 和待启动定时任务均停止。先认证/解压/解析并检查字段、类型及 eDAS 参数范围、FIP 包周期与共享周期，再应用完整配置。成功后保存为下次启动默认；统一快照写入失败则恢复原内存配置。导入不会自动开始通信/采集。

新增依赖 cryptography 已加入 requirements.txt。

- 导入非法字段/点数/路径、运行中导入保护、保存失败回滚。
- 从统一快照重新构造窗口，恢复 eDAS/FIP/字号/联合存储且不自动采集。
- 正常推进、等待/超时、写盘错误状态、重复联合通知去重。
- 文件成功计数、失败尝试/空文件/仅头 BZ 不计、重复停止不重复计数。
