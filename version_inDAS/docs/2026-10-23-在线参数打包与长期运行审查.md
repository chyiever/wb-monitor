# 在线参数、打包与长期运行审查

日期：2026-10-23；范围：version_inDAS 与 fipedasREAD，提交目标仅 dev2。

## 参数窗口与运行边界

- 采集窗口保留基础、硬件、相位处理及读取块/共享周期；裁剪起终点后显示合并后裁剪前通道数和裁剪后通道数，随 Points/Merge/Crop 实时更新。
- “DAS 独立存储”组新增独立存储窗口，包含保存包/文件时长、路径、格式、降采样、覆盖策略、压缩参数。“共享与显示”组新增窗口，包含绘图、滤波、显示时长、共享通道/降采样及距离坐标。
- 草稿只在应用并保存后生效；以当前配置为基底只提交本窗口修改项，避免旧窗口覆盖其他入口的新设置。运行期间后台再次校验硬件字段，不能靠修改禁用控件绕过限制。
- 在线显示修改同步到采集线程显示请求，不重建采集线程、不下发硬件。独立保存正在写文件时结构字段只读，关闭 SAVE 后可修改而不停止 DAS。
- 共享聚合器先保留完整空间块，按完整周期切片；在线共享范围改变不会混合不同形状片段。联合保存检测通道数/起点/步长/采样率的变化，提前截断旧分段并在后续文件写入新元数据；停止尾部同样分段。
- Tab1 绘图窗口继续允许在线滤波、显示、坐标、PSD/刷新调整；联合存储结构仍采用停止后修改的保护策略。

## 模块审查与改进

| 模块 | 检查结论及本次措施 | 验证边界 |
| --- | --- | --- |
| PCIe / 仿真采集 | 硬件、读取块与裁剪保持运行中不可变；显示请求单独更新；实际 DLL 操作沿用原流程。 | 仿真验证线程持续运行，未对真实驱动卡住或设备拔出认证。 |
| 独立 DAS 保存 | 既有按字节预算的队列、尾部排空、成功计数保留；在线修改文件结构前需关 SAVE。 | 压缩吞吐、磁盘性能依赖目标电脑；多个阶段预算不是总进程内存上限。 |
| 进程内共享 | 修复周期尚未收齐时切换范围的形状混合；聚合器使用 deque，避免队首 pop(0) 移动；完整周期工作集也校验预算。 | 共享周期固定，不能在线改为不同于 FIP 的周期；工作集和输入队列分别占用内存。 |
| 本机接收 / View | 既有有界邮箱、最新显示快照与绘图队列继续使用。 | UI 严重阻塞仍会导致积压，不能靠无限扩大缓存解决。 |
| FIP TCP / 处理 | 保留固定长度读取、非法包长断连重同步、双传感器拆分、处理队列与独立保存；本次未改线协议。 | 无真实发送端长时测试，包序号对齐不代表硬件同步。 |
| 对齐协调器 | 缺包历史最多 256 区间，累计计数独立保留；修复受保护未保存帧绕过裁剪后可能持续增长，按去重后的底层数组占用检查字节预算，超限发出一次故障并停止两路。 | 允许触发超限的最后一个包进入缓存以供排空；随后不再接受新包，下一会话重置故障。 |
| 联合写盘 | 成功后推进游标；具体异常类型/内容同步状态与尾部错误，日志保留堆栈。共享形状变化按文件切分。文件名使用微秒并检查冲突，不覆盖同一时间戳的已存在文件。 | 不承诺文件系统掉电保护；多实例同时写同一目录应分别设置输出目录。 |
| GUI / 全局样式 | 图标采用本地绘制的矢量线条，按钮 12 pt；重复应用字号时去除旧规则，避免 QSS 增长。 | 原生桌面命中测试需可交互 Windows 桌面。 |
| 配置 / 参数包 | 保留完整快照和 .par 验证；冻结程序的可写配置移动至 EXE 同目录，资源仍从包内读取。 | EXE 所在目录必须可写；.par 内置便携密钥不等同于密码访问控制。 |
| 回放 | BIN/bin32 只读映射、严格包体边界验证、拼接前像素预算、预览滤波有效采样率修正、文件版本缓存键、跳过排队中的旧请求。 | NPZ/H5 仍有整块加载/解压成本；映射文件不能在使用期间改写/删除。 |

## EXE 打包

`version_inDAS/build_exe.py` 调用 PyInstaller，默认单文件、无控制台，也支持 --onedir。只包含默认 app_config、资源和 DLL，不封装日志、用户快照、传感数据。--smoke-test 启动已打包 EXE，检查四个页面及 FIP/eDAS/对齐核心管理器初始化。源码启动与冻结启动分别检查配置路径。

构建依赖记录在 requirements-build.txt，dist/build/spec 与 EXE 排除 Git。fipedasREAD 使用其原 build_exe.py 重新打包，原 dist 目录继续排除。
