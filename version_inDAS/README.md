# wb-monitor 内置 eDAS 版本使用说明

版本：**v_inDAS_261021**。集成版本使用 `master2/dev2` 分支；本文及近期功能更新仅提交到 **dev2**。更新时间：2026-10-21。

软件将 PCIe-7821 eDAS 上位机与 wb-monitor 合并在同一进程，提供 eDAS 独立采集、FIP 独立通信和两路联合运行。相邻 `version_exDAS` 为外置 eDAS TCP 版本，阶段版本 `v_exDAS_261021`，对应 `master1/dev1`。

## 1. 安装和启动

在 `version_inDAS` 目录执行：

```powershell
python -m pip install -r requirements.txt
python run.py
```

无采集卡时，可使用软件生成的 eDAS 仿真数据：

```powershell
python run.py --simulate
```

仿真模式替换 eDAS 硬件数据源，FIP 仍使用真实 TCP 接口，需要外部 FIP 发送端才能收数。硬件模式需要 Windows、匹配采集卡的驱动及 `libs/pcie7821_api.dll`。启动脚本将工作目录固定在本版本目录，两个版本分别维护参数和日志。

每次启动恢复上次保存的参数，**不会自动启动通信或采集**。首次使用先检查硬件、FIP 网络、数据共享、存储路径和分段设置，再选择运行入口。

## 2. 三种运行模式与启停顺序

默认页面顺序：Tab1 **View**、Tab2 **eDAS**、Tab3 **FIP**、Tab4 **Setting**。Setting 中启用旧检测页后会多出一个名为 `Tab3` 的可选页面，Setting 的位置随之顺延；该旧页面名称不代表 FIP 页。

| 入口 | 操作及结果 |
| --- | --- |
| Tab2 eDAS 的开始采集 | 只启动本机 eDAS，不启动 FIP。可独立绘图和保存 DAS 数据；可与已启动的 FIP 同时运行。 |
| Tab2 eDAS 的停止采集 | 停止 eDAS 并排空其尾部数据，不停止 FIP。 |
| Tab3 FIP 的通信按钮 | 启动/停止 FIP TCP 服务及处理链路，不启动/停止 eDAS。启动服务后需等待 FIP 发送端连接。 |
| Tab1 View 的 Start | 按下表处理当前状态，建立联合运行顺序。重复点击不会叠加启动任务。 |
| Tab1 View 的 Stop | 取消所有等待中的联合启动；先停止并排空 eDAS，再停止 FIP。 |

**Start 的状态规则：**

| 点击前状态 | 执行顺序 |
| --- | --- |
| eDAS 和 FIP 都未运行 | 启动 FIP → 等待至少 1 s → 启动 eDAS。 |
| 只有 eDAS 在运行 | 停止两路并完成停止处理 → 等待至少 1 s → 启动 FIP → 等待至少 1 s → 启动 eDAS。 |
| 只有 FIP 在运行 | 停止两路并完成停止处理 → 等待至少 1 s → 启动 FIP → 等待至少 1 s → 启动 eDAS。 |
| eDAS 和 FIP 都在运行 | 保持当前运行，不停止、不重启、不重置对齐状态；Start 显示为不可重复操作。 |

等待使用 Qt 精确定时器，GUI 可继续响应；系统繁忙时实际间隔可能超过 1 s。Stop 和窗口关闭会取消等待任务，FIP 停止或启动失败会取消后续 eDAS 启动。eDAS 启动失败时提示检查采集卡及参数，FIP 保持运行，可单独停止或重试。

这里的“FIP 已运行”表示通信服务已启动，并不保证已有客户端连接或有效数据；请同时检查连接状态、数据计数和状态灯。1 s 启动间隔不是外部物理同步触发或采样时钟同步。

## 3. 软件架构与数据流

```text
run.py → src/main.py（应用生命周期、管理器绑定、退出清理）
                  │
                  ├─ ui/integrated_window.py：四页 GUI、参数快照、联合启停、状态面板
                  ├─ edas_hardware/：PCIe DLL / 仿真、相位处理、eDAS 绘图、独立保存
                  ├─ das/：本机共享数据接收、eDAS 管理与联合显示接口
                  ├─ fip/：TCP 接收、定点解码、处理、绘图、FIP 独立存储
                  └─ alignment/：两路包对齐、联合数据分发（联合写盘实现在 das/）

PCIe / 仿真 → eDAS 采集线程 ─┬→ 独立 DAS 保存（原始 int32，按 Save DS）
                            ├→ Tab2 波形 / PSD / 时空图
                            └→ 共享裁剪、降采样、弧度转换
                                → 进程内有界队列 → EDASManager ─┐
FIP 发送端 → TCP 服务 → Q40.24 解码 → FIP 处理管理器 ────────────┤
                          └→ FIP 独立保存                      │
                                                             ↓
                                              包序号 / 周期对齐
                                                   ├→ View 绘图
                                                   └→ 联合存储
```

eDAS 与 wb-monitor 之间通过本机共享对象和有界队列传递数据，**无需 eDAS TCP 连接**。`LocalDASSource` 保留管理器需要的接收接口，但不监听网络端口。FIP 仍通过 TCP 进入软件。

三个保存入口分别控制独立 DAS、独立 FIP、联合数据。绘图刷新、显示滤波与显示降采样用于显示链路；独立 DAS 的 Save DS、共享降采样、FIP 保存降采样和联合保存降采样分别作用于各自路径，不能互相替代。联合 DAS 数据来自共享后的数据，不等于完整原始采集卡数据。

对齐依据每次通信会话归一化后的包序号与配置周期。启动先后、重连和缺包会影响对齐，需查看 FIP 页的对齐状态及序号差。软件对齐不等同于两台设备具备共同硬件时钟或触发。

## 4. Tab1：View 联合显示和运行控制

### 4.1 曲线、绘图与状态

- **曲线选择**：为两条曲线选择 Off、DAS Channel、FIP1 或 FIP2；DAS 源需填写有效 CH。FIP2 需要实际配置并接收到双传感器数据。Off 关闭相应曲线。
- **绘图参数设置…**：打开详细绘图窗口；只有“应用并保存”才更新参数。取消或点击窗口外会放弃草稿。
- **存储参数设置…**：配置联合保存，详见第 8 节。
- **Start / Stop**：联合运行控制，按第 2 节状态规则执行。

运行状态区包括：

| 显示项 | 含义 |
| --- | --- |
| Fiber Length | 与 eDAS 页一致：Points × 0.4 m；超过 10 km 后用 km、保留 2 位小数，否则用 m、保留 1 位小数。 |
| 连续运行时长 | 任一路开始后计时；两路全部停止后保留该次时长，下一次启动重新计时。单路停止而另一路继续时不清零。 |
| eDAS / FIP 指示灯 | 结合采集/通信状态、实际数据进度、超时与错误显示状态。服务启动但未收数时不能视为数据正常。 |
| 存储指示灯 | 结合保存开关、成功完成文件和实际写盘错误判断。 |
| 磁盘剩余空间 | 已启用存储路径所在磁盘的余量；每 5 s 查询一次，不扫描历史目录。 |
| 已存储文件数 | 本次打开软件后成功完成的联合、FIP 和 DAS 文件数；不含历史文件及正在写入的文件。 |

状态颜色：灰色为未运行/未启用，黄色为等待数据或文件完成，绿色为数据有进展/文件完成，红色为异常、超时或磁盘不可用。判断异常时应结合日志和计数，不只看按钮颜色。

### 4.2 绘图参数窗口

| 小页 | 参数用法 |
| --- | --- |
| FIP 绘图 | 设置滤波开关、频段、阶数、相位展开、时间降采样及处理目标传感器。频段需符合有效采样率范围。 |
| DAS 绘图 | 设置 View DAS 曲线的显示滤波频段和阶数。 |
| 显示与刷新 | 设置时间窗口、FIP/eDAS 刷新周期、每曲线最大点数，以及时域、PSD、时空图和刷新开关。减少点数/刷新频率可降低显示负担。 |
| PSD | 控制两路 PSD、Welch 时间窗口和重叠比例。窗口越长，频率分辨率越细，也需要更多数据。 |
| 坐标轴 | 设置手动 X/Y 及 PSD Y 范围；关闭手动范围后恢复自动缩放。 |
| 时空图 | 设置 CH 范围、总时间窗、移动步长、时间/空间降采样、配色、去基线、自动色标或手动上下限。 |

## 5. Tab2：eDAS 采集、绘图和独立保存

### 5.1 主区按钮和摘要

**开始采集 / 停止采集**只控制 eDAS。**独立保存开关**控制 DAS 文件写入，**共享到 View / 联合存储**控制内部数据分发；关闭共享不停止 eDAS 采集、绘图或独立保存。

点击 **采集参数设置…** 打开七个小页，采集运行时参数只读，需先停止再修改。参数窗口外点击或取消会放弃草稿，只有 **应用并保存** 通过校验后写入。硬件参数在下次开始采集时下发。左右参数区宽度可拖动，与 View 参数区联动。

主区摘要按行显示 Scan、Fiber Length、dx、GL、PolarDiv、Detrend/绘图滤波、crop：

- Fiber Length = Points × 0.4 m。
- dx = 0.4 × Merge m，表示合并后空间步长。
- GL = 0.4 × Merge × DiffOrder m。
- PolarDiv 绿/红表示该配置启用/关闭，不是硬件健康状态。
- 裁剪参数使用 `[CropStart, CropEnd)`，CropEnd=0 表示取到末尾。摘要显示实际保留的包含端点范围 `crop: CH a~CH b (Total: nCH, 距离)`，距离为 n × dx。

### 5.2 采集参数窗口

| 小页 | 参数与使用方法 |
| --- | --- |
| 基础采集 | Scan 为每秒扫描次数；Pulse 为脉冲宽度 ns；Points 为每次扫描点数，修改后旁边预览 Fiber Length。Channels 设置上传通道数，Source 选择采集卡上传类型。共享模式要求单通道 PHASE。 |
| 硬件设置 | 设置内部/外部时钟、触发方向、Bypass 跳过点数、中心频率 MHz、DataRate、Rate2Phase 和 PolarDiv。按实际接线与采集卡配置设置，不能用显示参数替代硬件参数。 |
| 相位处理 | SpaceAvg 为空间平均；Merge 为空间合并，旁边预览 dx；DiffOrder 决定空间差分间距，旁边预览 GL；Detrend 设置去趋势带宽；CropStart/CropEnd 控制处理后保留范围。 |
| 时长设置 | Length/Load 为每次 DLL 读取块时长；Length/Plot 为显示窗口时长；Length/Save 为保存包时长；Length/File 为单文件分段时长；Length/Comm 为共享周期。时长会换算为整数扫描帧，按界面提示满足块长和倍数约束。共享启用时 Comm 必须等于 FIP 包时长。 |
| 独立存储 | 设置路径、BIN/BZ、Save DS、满盘覆盖最旧文件、Zstd 级别、Bitshuffle 块长度和 BZ 压缩线程数。Save DS 越大保存的时间采样越稀疏；覆盖开关涉及旧数据删除，启用前确认目录。 |
| 绘图显示 | 设置波形 Region、相位 rad 显示、显示滤波/频段、时空图空间范围、窗口块数、时间/空间显示降采样、色标上下限、配色，以及纵轴单位和 x0。仅改坐标单位不会改变落盘数据。 |
| 数据共享 | 设置共享开关、CH 起止（终点包含）、时间和空间降采样。共享会影响 View 和联合保存的 DAS 范围/采样率，不改变独立 DAS 原始保存范围。 |

### 5.3 波形、PSD 和时空图

- **Phase / RAW / Monitor**：选择相位、原始数据或监视通道。Phase↔RAW 会改变硬件上传方式，必须停止后切换；RAW 不支持 4 上传通道。Phase↔Monitor 可在线切换。
- **显示 PSD**：勾选显示频谱；取消后时空图自动增高填满空余区域。
- **TIME / SPACE**：沿用原 PCIe 上位机语义。TIME 显示一帧沿光纤的空间波形；SPACE 显示指定 CH 随时间变化的波形。SPACE/Monitor 与时空图时间轴联动；TIME/RAW 的横轴含义不同，不建立该时间联动。
- **CH**：SPACE/Monitor 下选择通道，从裁剪后的首个通道 0 开始。应在有效裁剪范围内选择。
- **时空图纵轴**：在采集参数窗口选择 Points、Distance (m) 或 Distance (km)。距离为点号×dx+x0；km 模式中 dx 先换算为 km。x0 使用当前选定单位，默认 0；改单位时应同时核对 x0。

波形、PSD、时空图保持绘图区宽度一致。图形默认 Times New Roman 12 pt；通过 Setting 全局入口统一调整。

## 6. Tab3：FIP 通信、对齐和 FIP 独立存储

### 6.1 通信设置和按钮

设置监听 IP、端口、FIP 包时长、每传感器采样率和传感器数量，然后点击 **FIP 通信按钮**启动服务。默认监听地址 `0.0.0.0:3677`，表示本机所有网卡；发送端应连接运行本软件电脑的实际 IP，而不是把 `0.0.0.0` 当作目标地址。监听启动成功后等待发送端连接；防火墙需允许对应 TCP 端口。

包时长和采样率必须与发送端一致；采样率字段使用 MHz，例如 1 MHz 填写 1。单/双传感器配置必须与发送端数据排列一致。统计区显示连接、收包、缺包、速率、通信序号和对齐状态。清除统计用于重置界面统计，不会修复发送端数据或补回缺包。

该页没有 eDAS TCP 启用按钮。eDAS 状态来自本机采集与共享，独立启停请到 Tab2；联合启停请到 Tab1。

### 6.2 FIP TCP 协议

接收实现位于 `src/fip/tcp_server.py`，协议如下：

| 字段 | 字节与编码 |
| --- | --- |
| 包头前 4 字节 | `comm_count`，大端无符号 32 位整数。 |
| 包头后 4 字节 | `data_length`，大端无符号 32 位整数，表示随后的数据体字节数。 |
| 数据体 | 大端有符号 64 位 Q40.24 定点数序列；字节数应为 8 的倍数，解码为 float64，数值 = int64 / 2^24。 |
| 双传感器排列 | 逐采样交织：FIP1[0]、FIP2[0]、FIP1[1]、FIP2[1]……；单传感器直接使用整个序列。 |

TCP 为字节流，接收端按包头/包体长度读取，支持分次到达。非法长度会关闭当前连接并等待重连以恢复字节边界。原始通信序号保留用于诊断，会话内归一化序号用于处理/对齐；序号跳跃记入缺包统计。解码值的物理含义以 FIP 设备标定为准。

### 6.3 本页存储和配置控制

- **FIP 独立存储**：启用后按路径、保存间隔和 FIP 降采样写入 NPZ。单传感器保存一路，双传感器保存拆分后的两路；文件为保存链路数据，不等于 View 当前经过显示滤波的曲线。
- **存储日志/统计**：查看 FIP、eDAS、联合数据的完成/失败、最近文件与写入信息。联合开关和参数入口已迁至 View。
- **保存配置 / 加载配置 / 重置配置**：管理 GUI 配置。运行前保存，加载或重置前停止两路；跨机器携带完整传感参数推荐使用 Setting 的 `.par` 导出/导入。

## 7. Tab4：Setting、配置恢复与参数包

**应用并保存全局设置**保存 GUI 字号、所有图刻度与标签字号、PSD 降采样等。默认 GUI 参数文字 10 pt、按钮 14 pt、图形文字 Times New Roman 12 pt。图形字号统一作用于 View 和 eDAS，含时域、PSD、时空图。可选检测页默认隐藏，按需要启用；检测页保留特征计算、阈值、触发前后存储和报警历史功能。

**导出参数**选择 `.par` 文件，导出当前完整 FIP/eDAS、绘图、共享、存储和全局配置，不含传感数据、运行计数或采集状态。**导入参数**需要停止两路且没有等待启动任务；软件先验证封装、认证和参数类型/范围/周期一致性，通过后应用并保存，下次启动继续使用。导入不启动采集或通信。

`.par` 使用带版本头的二进制封装、压缩 JSON、随机 nonce 和 AES-256-GCM 加密认证，普通文本编辑器无法直接读取参数，篡改会被拒绝。程序使用内置便携密钥，便于相同软件跨机器导入；这是一种非明文封装和完整性保护，不是用户密码访问控制，也不承诺抵抗源码分析。依赖 `cryptography`，安装见 requirements。

默认 GUI 快照为 `config/gui_last_state.json`，包含完整 eDAS 参数。旧 `config/edas_last_params.json` 用于兼容恢复；eDAS 参数保存会同步统一快照。参数窗口中未点击“应用并保存”的草稿不属于默认配置。启动快照异常时检查日志，并重新保存有效参数。

## 8. 联合存储与高速写入

### 8.1 入口和参数

在 View 点击 **存储参数设置…**，设置联合保存开关、保存路径、分段间隔、FIP 保存降采样、缓存时长、文件格式和 H5 压缩。应用并保存后生效。采集/通信运行中仅允许切换联合保存开关；要修改路径、格式、分段或数据形状参数，先停止两路。

联合保存需要 FIP 数据与 eDAS 共享数据进入对齐链路。请启用单上传通道 PHASE 共享，并使共享周期与 FIP 包时长一致。只启动单路时可以独立保存，不能形成完整双路联合包。共享关闭后独立 DAS 仍可保存。

### 8.2 格式与数据精度

| 保存入口/格式 | 数据与用途 |
| --- | --- |
| eDAS 独立 BIN | 原始 int32 计数，按 Save DS 保存；适合优先降低 CPU 压缩开销。 |
| eDAS 独立 BZ | 原始 int32，经 Bitshuffle + Zstd 压缩；吞吐取决于数据可压缩性、CPU 与线程设置。 |
| FIP 独立 NPZ | 未压缩 NPZ，保存 FIP 保存链路数据和元数据；双传感器按两路组织。 |
| 联合 bin32（默认） | 魔数 `FIPeDAS2`；FIP float64、DAS float32 弧度，兼顾容量与吞吐。float32 约 7 位有效数字。 |
| 联合 bin | 旧魔数 `FIPeDAS1`，DAS 使用 float64；同等 DAS 数据所需空间约为 int32 的两倍。 |
| 联合 npz / h5 | 便于分析；压缩会增加 CPU 开销。H5 需可用的 h5py；缺少依赖时实现会回退到 BIN，应检查日志和实际文件。 |

需要完整原始计数时启用独立 DAS 保存，不能用共享后 float32 联合数据替代。根目录 `fipedasREAD` **源码**支持 bin32；历史 `dist` EXE 未重打包，不支持新格式，上传时也排除该目录。

### 8.3 排空、错误与性能边界

采集、共享和保存通过有界队列分离。停止时排空队列及文件尾部；不要在“正在停止/排空”时强制结束进程。DAS 完成文件在 flush/fsync/close 成功且包含数据后计数；FIP 完成数只统计成功写入；联合 BIN/bin32 通过临时 `.part`、刷新和重命名发布完成文件。

队列溢出、内存字节预算或磁盘错误会报告故障；部分链路会停止采集以避免继续扩大丢失。故障会话不能当作完整无损采集，需检查日志、剩余空间、磁盘持续写速及存储参数。

此前 E 盘 10 秒合成实盘测试：600 MB/s 输入下独立/联合同时保存无丢块，bin32 停止排空约 47 ms。该结果仅覆盖当次短时合成测试，不代表真实采集卡、BZ/H5 压缩或长时间持续运行均达到相同能力。现场应使用目标磁盘和实际格式复测，预留文件系统、SSD 缓存耗尽与后台任务带来的吞吐余量。

## 9. 常见检查与开发验证

| 现象 | 检查项 |
| --- | --- |
| eDAS 无法开始采集 | 检查 DLL、驱动、采集卡连接、硬件参数和日志；无硬件使用 `--simulate`。 |
| FIP 服务已启动但没有数据 | 检查发送端目标 IP/端口、网络、防火墙和连接状态；启动监听不会生成 FIP 数据。 |
| eDAS 正常但 View 没有 DAS | 检查共享开关、单通道 PHASE、共享周期与 FIP 包时长、CH 范围及降采样。 |
| 联合保存没有完整文件 | 检查两路收数、对齐、联合保存开关、磁盘、分段时长；正在写入的文件不计为完成文件。 |
| 参数不能改/下次启动没变化 | 运行时采集参数只读；停止后修改并点击“应用并保存”，窗口外点击会放弃修改。 |
| 灯变红或文件数停止增长 | 查看 `logs/` 及 FIP 页存储日志，区分无数据、处理失败、队列拥塞、缺包和磁盘错误。 |

关键目录：`src/ui` 为界面和参数包，`src/edas_hardware` 为采集卡与独立保存，`src/das` 为本机共享管理，`src/fip` 为 FIP 通信处理，`src/alignment` 为对齐/联合保存，`tests` 为自动回归，`docs` 为开发说明，`logs` 为运行日志及测试报告。

从本版本目录运行验证：

```powershell
python -m unittest discover -s tests -v
python -m compileall -q src
python src/tools/benchmark_storage.py --directory E:/scratch/wb-test --seconds 10 --joint-format bin32 --report result.json
```

存储基准使用临时数据并自动清理，需在目标盘预留足够空间。自动测试覆盖仿真采集、共享/对齐/回读、参数校验、绘图交互、独立/联合启停和保存异常；真实硬件、物理同步和长时间高速运行仍需现场验证。
