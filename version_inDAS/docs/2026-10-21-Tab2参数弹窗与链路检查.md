# 2026-10-21 Tab2 参数弹窗与链路检查

## 问题及修复

上一版已复制原 PCIe-7821 Setting 页面及其配置、DLL 调用代码，但把旧页面直接搬入新的参数区时，仍保留了旧 QTabWidget 的显隐状态、父窗口关系和控件样式。旧参数区的最大高度、固定宽度也与主界面控件尺寸不一致，导致参数不易发现、部分编辑器被裁切或不能正常操作；下拉列表的定位也受旧窗口层级影响。

本次保留原控件作为内部配置适配层，界面上使用独立 QDialog 中新建的编辑器。新编辑器从原控件读取范围和选项，以配置草稿工作，完成校验后统一应用。弹窗直接属于主窗口，不依附于隐藏的旧标签页。

## 主参数区

- Tab2 使用与 View 相同的全局字体、浅色卡片、控件和操作按钮风格。
- 默认宽度 448 px，允许 360～720 px 范围内拖动调整，与 View 的参数宽度联动；使用已有 View 宽度配置持久化。
- 主参数区只显示采集摘要、存储路径、文件/包时长、降采样、共享范围和绘图配置结果。
- 保留启动/停止、DAS 独立存储开关和共享开关；具体数值通过“采集参数设置…”修改。
- 主区取消旧参数横向长表和横向滚动，不再在隐藏页面中寻找原 Setting 参数。

### 编辑与生效规则

1. 打开弹窗后编辑独立草稿；取消不改变当前配置。
2. “应用并保存”先检查点数对齐、时长整数帧数和倍数关系、色标范围、滤波参数、共享通道范围及 FIP 周期一致性。
3. 校验不通过时在弹窗内显示原因，不写回配置。
4. 合法配置写回原有参数适配层，再通过原保存函数写入本版本 `config/edas_last_params.json`。
5. 硬件参数在下次启动采集时，通过原 `_configure_device()` 下发；编辑草稿和保存配置不会提前调用硬件 DLL。
6. 采集中打开弹窗为明确的只读模式，且应用入口有二次保护；停止后重新打开可编辑，避免中途改变采集形状或文件格式。

另外修复启动时强制开启共享开关的问题，现在保留已保存的关闭状态。共享通知不再使用 TCP 发送器表述。不足一个共享周期的尾部只在启用 DAS 独立保存时保留原始块，界面提示不再无条件声称已保存。

## 完整软件数据流核对

```text
弹窗草稿
  → 参数校验
  → 原 UI 适配层与 AllParams
  → edas_last_params.json
  → 下次采集启动时重新收集配置
       ├─ _configure_device → PCIe DLL 参数与 DMA 缓冲分配
       ├─ AcquisitionThread.configure → Load 帧数、形状、显示快照节奏
       ├─ 完整原始块 → 独立 BIN/BZ 保存
       ├─ 裁剪后的完整 PHASE → 进程内共享 → 原对齐/联合保存 → 回放
       └─ 显示快照 → eDAS 波形/PSD/时空图、View
```

| 参数 | 下游逻辑 | 验证 |
|---|---|---|
| Clock/Trig/Scan/Pulse/Points/Bypass/CenterFreq | DLL 设置接口 | 用 Mock DLL 核对具体参数；MHz 转 Hz |
| Channels/Source/DataRate | `set_upload_data_param` | 核对选项值与调用 |
| Rate2Phase/SpaceAvg/Merge/DiffOrder/Detrend/PolarDiv | `set_phase_dem_param` | 核对弹窗草稿到 DLL 参数 |

## 21:04 反馈补充：设备失败警告导致鼠标点击错位

用户报告“采集参数设置”和其他 eDAS 按钮无响应。该次日志中 FIP 的启动、停止仍能正常执行，因此不能将此问题仅归结为采集卡打开失败。

Windows 原生 Qt 实验中，设备打开返回 -1 后，构造阶段的 QMessageBox 会在 eDAS 页面尚未嵌入主窗口时建立原生窗口并进入嵌套事件循环。随后页面显示正常，但按钮屏幕坐标处的 QApplication.widgetAt 返回 QTabBar 或其他控件，点击没有到达按钮。仿真模式没有设备警告，直接调用槽函数也绕过了鼠标命中，因此此前测试漏检。

修复将设备初始化通过 QTimer.singleShot(0, ...) 延后至页面已嵌入、主窗口已构造完成之后，并删除重复 setWindowFlags(Qt.Widget)。硬件失败仍明确报警，关闭警告后允许编辑参数和操作页面。

新增 test_native_interaction.py，在独立 Windows 原生 Qt 进程中 Mock 设备打开返回 -1，验证初始化确实发生在构造结束后、警告只出现一次、参数按钮屏幕坐标能命中自身、参数弹窗显示、启动信号及独立保存/共享开关可切换。该回归测试不使用 offscreen 平台。完整测试数增至 23 项且通过；不代表实际采集卡连接测试通过。

## 采集摘要与参数草稿窗口更新

窗口默认宽度调整至 840 px，保持七个设置页。窗口不再阻止主界面接收事件，点击窗口外会取消并关闭，外部点击本身被消费；点击内部下拉列表或所属文件选择窗口不会取消。切换其他应用也会取消草稿。仅“应用并保存”执行校验和写回，取消、窗口关闭与外部点击均不更新配置或 JSON。

主面板“采集参数”固定七行：Scan；Fiber Length（Points×0.4 m）；dx（0.4×Merge m）；GL（dx×DiffOrder m）；Polardiv 绿灯开启/红灯关闭；Detrend 与绘图滤波；crop。Pulse、Points 数值、上传通道/DataRate 和时钟/触发等仍可在设置窗口调整，摘要不再展示。

设置窗口中，Points 后实时显示 Fiber Length，Merge 后显示 dx，DiffOrder 后显示 GL，均根据当前草稿联动。Fiber Length 和裁剪长度只有超过 10000 m 才切换到 km，m 保留一位小数、km 保留两位小数。dx、GL 始终以 m 显示。

crop 摘要使用实际保留的通道编号，范围两端均是实际保留通道；底层输入仍使用 [CropStart, CropEnd)，CropEnd=0 表示使用全部剩余通道。例：Points=32768、Merge=4、CropStart=2、CropEnd=202，dx=1.6 m，摘要为 CH 2~CH 201（Total: 200CH，320.0 m）。不修改原有裁剪、共享或存储算法。

验证增至 25 项自动测试，包括 10000 m 单位边界、草稿实时换算、七行摘要、红色关闭指示灯、实际裁剪总数、窗口外点击取消且配置/JSON 不变，以及 Windows 原生屏幕命中和外部点击。已查看摘要、基础采集与相位处理页面的渲染结果。本次仅更新 dev2。

## 绘图控制、字号与物理距离坐标

PSD 不显示时其网格行高度归零，时空图扩展填满下方区域。三个绘图区同列，采用相同左轴宽度；字号增大时同步扩大左轴预留空间，避免破坏波形与时空图的水平对齐。“绘图显示”新增字号设置，默认 12 pt，可选 8～28 pt，刻度与轴标签统一 Times New Roman，保存到 eDAS 配置。

波形数据源有 Phase、RAW、Monitor。Phase 和 RAW 来自采集卡不同上传模式，停止后可切换；运行中尝试跨模式切换会恢复原选择并显示提示，4 通道 RAW 会被拒绝。RAW 通过原 raw DLL 配置和 RAW 波形/频谱绘制，时空图隐藏并明确说明无 PHASE 数据。Monitor 读取原独立 Monitor 数据，允许在 PHASE 采集中在线切换，不更改保存或共享数据源。

Phase 的 TIME/SPACE 下拉框与 CH 输入位于“显示 PSD”之后。沿用原 PCIe 上位机语义：TIME 是每帧沿光纤的波形（横轴 m）；SPACE 是指定空间通道随时间变化（横轴 s），CH 输入仅 SPACE/Monitor 可用，编号从裁剪后的 CH 0 开始。空间模式与时空图时间轴联动；TIME/RAW 解除时间轴联动。采集显示快照新增一个完整分辨率空间帧，供 TIME 绘制，SPACE 仍使用完整采样率单通道进行时域/PSD，不继承图像降采样。TIME 显示空间频谱（1/m），避免将其误标为时间频率 Hz；滤波启用时沿用已滤波的空间显示帧及其空间采样间距。

参数窗口新增纵轴 Points / Distance (m) / Distance (km) 和 x0。dx=0.4×Merge m；m 模式 y=point×dx+x0，km 模式 y=point×dx/1000+x0。x0 默认 0，使用所选距离单位，Points 模式不应用偏移。所选显示范围的起点及空间降采样均计入坐标，图像每个像素中心对应实际通道距离；TIME 空间波形也使用相同物理原点（横轴始终 m）。原始数组及通道编号不转换，保存、共享、裁剪和对齐不受影响。

新增 test_edas_plot_controls.py：实际检查隐藏 PSD 后无空白网格行、时空图增高、下边界填满；检查字体、PSD、纵轴单位/x0 重启恢复；回读像素中心在 m/km 下的坐标并确认数组不变；用合成帧核对 SPACE 选中通道和 TIME 最新全分辨率帧；核对 RAW DLL 源及波形数值、运行中切换保护与 Monitor 在线切换。完整测试共 29 项，仍不代替真实采集卡联调。
