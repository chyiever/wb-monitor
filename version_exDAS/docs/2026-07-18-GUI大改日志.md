# 2026-07-18 GUI大改日志

## 背景

本轮修改来自 2026-07-18 半天 FIP/eDAS 联调日志和现场 GUI 使用反馈。日志显示通信链路本身较稳定，但旧界面把 FIP 绘图、eDAS 绘图、通信控制、存储控制分散在多个 tab 中，且旧 Tab1 绘图线程仍可能清空图件，影响合并后的波形视图。

## 设计目标

1. 将旧 Tab1 和旧 Tab3 的绘图能力合并到新的 `View` tab。
2. 将通信、同步检验、存储控制和运行计数统一到新的 `Data` tab。
3. 保留旧 Tab2 检测功能，移动为新的第三个 tab，默认不启动。
4. 将旧 Tab4 改为 `Setting`，用于全局 GUI 与图件字体设置。
5. 新增 FIP/eDAS 同步时间差显示，辅助判断两个物理联动采集模块是否真正同步。

## 完成内容

### View tab

1. 新 tab 名称为 `View`，位于第一个 tab。
2. 左侧参数区包含曲线源、FIP 预处理、刷新频率、PSD、坐标轴和 Space-Time 参数。
3. 右侧绘图区采用水平 splitter：左侧为 Curve1/Curve2 时域图，右侧为 PSD 图，初始宽度约 `7:3`。
4. Curve1/Curve2 支持 `Off`、`DAS Channel`、`FIP/FIP1/FIP2`，根据当前源自动更新。
5. PSD 图合并显示 `PSD1` 与 `PSD2`，共用一个 dB 坐标轴，添加 legend。
6. PSD 使用 Welch 法计算，窗口长度和重叠率由左侧参数控制。
7. 支持手动关闭 PSD1 或 PSD2。
8. 保留 pyqtgraph 默认缩放、平移、框选和滚轮交互，并增加手动时域 X/Y 范围、PSD Y 范围设置。
9. 旧 Tab1 绘图线程已从可见图件解绑，避免 FIP 启停时清空或覆盖新的 View 图件。

### Data tab

1. 新 tab 名称为 `Data`，位于第二个 tab。
2. 整合 FIP 和 eDAS 的 IP、端口、包时长、采样率、传感器数量等通信参数。
3. 新增三个通信按钮：
   - `同时启动FIP+eDAS`
   - `启动FIP通信`
   - `启动eDAS通信`
4. 新增两个通信指示灯：
   - 未启动为灰色
   - 已启动但未成功通信为红色
   - 已确认连接或收到数据为绿色
5. 通过 `通信统计` 表统一显示 FIP/eDAS 状态、接收包、缺包/失败、丢包率和最近 Comm。
6. 同时启动时重置同步统计，实时显示：
   - 首包时间差（FIP-eDAS）
   - 最新同序号时间差（FIP-eDAS）
   - 平均时间差（FIP-eDAS）
   - 匹配包数
7. 新增三个存储按钮：
   - `同时存储FIP+eDAS`
   - `FIP存储`
   - `eDAS存储`
8. 新增两个存储指示灯和 FIP/eDAS 存储成功/失败计数。
9. Data tab 不包含绘图控件，定位为通信、同步、存储和配置操作面板。

### Tab3

1. 旧 Tab2 检测功能移动为新的第三个 tab。
2. 原检测参数、特征显示、告警表等内容保持不变。
3. 默认不启动，仍由 `Start/Stop Tab2` 总开关控制。

### Setting

1. 旧 Tab4 改名为 `Setting`。
2. 新增全局字体设置：
   - GUI 字体大小
   - 图件标题字体大小
   - 坐标轴标签字体大小
   - 坐标刻度字体大小
3. 点击 `保存全局设置（重启生效）` 后保存配置；全局显示设置需重启软件后生效。

## 代码变更

1. `src/ui/main_window.py`
   - 重构 tab 顺序和布局。
   - 新增 View/Data/Setting 控件。
   - 新增 PSD Welch 计算、曲线缓存、轴范围设置、状态灯、通信/存储计数和同步时间差显示。
2. `src/main.py`
   - FIP 收包时转发 TCP 完整包体接收时间，用于 FIP/eDAS 同序号包时间差检验。

   - 旧 Tab1 绘图线程不再绑定 View 图件。
3. `src/das_tab3/das_tab3_manager.py`
   - eDAS 收包时转发 TCP 完整包体接收时间。

4. `src/fip_tab1/fip_tab1_manager.py`
   - `set_plot_widgets(None, None)` 时主动清除旧曲线引用，防止后台线程继续写旧图件。

## 剩余注意事项

1. 本轮 GUI 只改变显示与控制组织，不改变 FIP/eDAS TCP 包协议。
2. 半天日志中 FIP 原始相位仍存在 `decoded_range=[-2.14748365e+09, 2.14748365e+09]`，该问题应继续作为硬件/发送端协议语义待确认项。
3. 新同步时间差基于 TCP 完整包体到达主机的时间，不等价于设备内部硬件时间戳；它用于检验联调链路的整体同步与实时通信表现。

## 2026-07-19 GUI细节修正

### 服务端监听地址

1. Data tab 中 FIP/eDAS 的 `IP` 标签改为 `监听地址`。
2. 默认监听地址保持 `0.0.0.0`，表示本软件作为服务端监听当前电脑所有网卡。

## 2026-07-19 参数自动保存与启动恢复

### 功能说明

1. 新增本地 GUI 参数快照文件：`config/gui_last_state.json`。
2. MainWindow 构造时会在默认控件创建完成后自动读取该快照，并恢复上次关闭前的参数。
3. GUI 参数变化后通过 `QTimer` 做 `700 ms` 防抖自动保存，减少连续编辑时的磁盘写入。
4. 窗口关闭前会强制保存一次，保证最后一次修改落盘。
5. 保存采用 UTF-8 JSON，并先写入临时文件再替换目标文件，避免写入中断导致快照损坏。
6. GUI 快照与基础系统配置 `config/app_config.json` 分离，`保存配置` 不再把现场 UI 参数覆盖到基础配置文件。

### 恢复范围

1. Data tab：FIP/eDAS 监听地址、端口、FIP 单包时长、采样率、传感器数量、存储路径和存储间隔。
2. View tab：曲线选择、滤波参数、刷新间隔、曲线点数、PSD 开关、Welch 窗长、重叠率、手动坐标轴范围。
3. Space-Time：通道范围、时间/空间降采样、色图、`Vmin/Vmax`。
4. Tab3 检测页：特征选择、检测滤波、窗口、阈值和触发存储参数。
5. Setting tab：GUI 字体、图题字体、坐标轴标签和刻度字体。

### 运行保护

1. 启动恢复只恢复参数，不自动启动 FIP/eDAS 通信。
2. 检测页总开关恢复为关闭，避免打开软件后后台检测线程自动运行。
3. FIP 通信启动前会从 GUI 同步当前监听地址和端口，确保上次恢复的地址/端口真正用于服务端监听。
4. 本地快照文件加入 `.gitignore`，防止现场参数误提交到 GitHub。

## 2026-07-19 View/Data布局二次调整
