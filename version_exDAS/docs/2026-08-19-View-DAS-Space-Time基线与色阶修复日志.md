# 2026-08-19 View DAS Space-Time 基线与色阶修复日志

## 1. 问题现象

View 页的 DAS Space-Time 图长期以深蓝或深红为主。即使把手动 V 范围从 `-1~1` 扩大到 `-3~3`，图像仍基本不变；与此同时 Data 页的 eDAS 收包计数持续增长。

现场导出的测试文件为：

- `0000001-eDAS-10000Hz-0051ch-10000pt-20260819T172552.950.bin`
- `0000001-eDAS-10000Hz-0051ch-10000pt-20260819T172552.950.json`

## 2. 数据检查结论

文件包含 10 个完整数据块，每块矩阵形状为 `51 x 10000`，共 5,100,000 个 `float64` 样本。

- NaN：0
- 正负 Inf：0
- 全局最小值：`-13.0097046`
- 全局最大值：`12.7131579`
- 相邻包完全相同的样本比例约为 `0.06%`，确认数据一直在变化
- `5,000,000` 个样本满足 `abs(value) > 3`，占 `98.0392%`，刚好对应 51 个通道中的 50 个通道

多数通道含有很大的固定相位基线。例如：

| 通道 | 均值 | 标准差 |
| --- | ---: | ---: |
| 0 | -12.5097 | 0.0368 |
| 8 | 12.4716 | 0.0411 |
| 22 | -12.5106 | 0.0328 |
| 48 | 0.0205 | 0.0719 |
| 49 | 12.4145 | 0.0705 |

大量通道的基线接近 `±4π`。原始数据上的小幅噪声变化被固定基线和手动色阶完全淹没，因此图像看起来长期不变。该现象不是收包停止，也不是导出文件中的数据包重复。

## 3. 原代码问题

### 3.1 Space-Time 直接绘制绝对相位

`DASPlotWorker._build_space_time_payload()` 仅从原始矩阵抽取通道和时间点，没有去除各通道不同的固定相位基线。固定 `±0.3`、`±1` 或 `±3` 色阶都会导致大部分通道饱和。

### 3.2 绘图帧共享后台滚动缓冲

原代码通过 `np.ascontiguousarray()` 返回滚动缓冲的切片。缓冲填满后，该调用可能不复制数据，导致发给 Qt UI 的矩阵仍与 `_space_time_buffer` 共享底层内存。绘图线程继续原地移动和覆盖缓冲时，UI 和 pyqtgraph 持有的旧帧也会被后台修改。

### 3.3 色阶长期固定且自动计算函数未接入实时路径

实时绘图一直读取手动 V 范围并设置 `autoLevels=False`。已有的分位数函数没有参与实时绘图，无法适应去基线后不同实验的噪声幅度。

## 4. 修复内容

### 4.1 显示副本逐通道去基线

在滚动窗口生成完成后，创建独立的 C-order `float32` 副本，并按时间轴计算每个通道的中位数：

```python
matrix = np.array(
    self._space_time_buffer[:, :visible_cols],
    dtype=np.float32,
    copy=True,
    order="C",
)
baseline = np.nanmedian(matrix, axis=1, keepdims=True)
matrix -= baseline
```

中位数比均值更不容易被短时冲击信号拉偏。处理只作用于绘图副本；TCP 接收矩阵、对齐缓存、joint 存储和 eDAS raw 存储全部保持原始数据。

### 4.2 修复跨线程共享内存

使用 `np.array(..., copy=True, order="C")` 保证每个 `plot_payload_ready` 都携带独立矩阵。后台滚动缓冲后续更新不会修改已经交给 UI 的帧。

### 4.3 增加 View 控件

Space-Time 参数区新增：

- `逐通道去基线`：默认开启
- `自动色阶`：默认开启
- 手动 V 范围默认改为 `-1~1`；自动色阶开启时禁用该输入框

两个开关均接入 GUI 配置保存和恢复。去基线关闭时可查看原始绝对相位；自动色阶关闭时继续使用手动 V 范围。

### 4.4 稳健的对称自动色阶

自动色阶根据去基线矩阵的 `abs(value)` 99.5% 分位数生成对称范围：

```text
levels = (-P99.5(abs(matrix)), +P99.5(abs(matrix)))
```

默认 Seismic 是以 0 为中心的发散色图，因此对称范围比独立的低、高分位数更合适。色阶上限使用 `alpha=0.2` 的指数平滑，降低逐帧闪烁。

开始新会话或清空 Space-Time 图时会重置平滑状态。

### 4.5 增加原始 DAS 数值诊断日志

每 50 包从原始矩阵中最多等步长抽取约 100,000 个样本，记录：

- min / max
- 1% / 99% 分位数
- median
- NaN / Inf 数量

日志节点为 `TAB3_NODE manager.das_values`。有意采用有界抽样，避免对最大规格 DAS 包执行全矩阵分位数计算。

## 7. 实机复测建议

1. 保持 `逐通道去基线` 和 `自动色阶` 开启，观察 5 秒滚动窗口是否持续变化。
2. 关闭自动色阶并设置 `V范围=-1-1`，确认本次数据仍能显示噪声结构。
3. 关闭去基线，确认图像恢复为原始绝对相位的红蓝饱和效果，用于对照。
4. 在日志中检查 `manager.das_values`，确认原始值域、NaN 和 Inf 状态稳定。
5. 实机产生冲击信号时，确认中位数基线不会削弱短时异常；如果需要保留极低频变化，可后续增加固定基线标定模式。
